## Progressive Web App (PWA) Enhancements (Added Jan 2025)

### Overview

Readest's web platform received significant PWA enhancements in January 2025 (commits ee0d7d7a, c8bfb64a, c678d8fa, d757555f), transforming it into an installable, offline-capable application with native app-like experience.

### PWA Configuration

**Manifest** (`public/manifest.json`):
```json
{
  "name": "Readest",
  "short_name": "Readest",
  "start_url": "/",
  "display": "standalone",
  "background_color": "#ffffff",
  "description": "Readest is an open-source eBook reader supporting EPUB, PDF, and sync across devices.",
  "icons": [
    { "src": "/icon.png", "type": "image/png", "sizes": "192x192" },
```

**Service Worker** (`next.config.mjs`):
```javascript
import withPWA from 'next-pwa';

export default withPWA({
  dest: 'public',
  disable: appPlatform !== 'web',

  skipWaiting: true,

```

### Dynamic Theme Color

**Implementation** (`src/hooks/useTheme.ts`):

PWA browser UI color changes dynamically based on:
- User's selected theme (9 options: default, gray, sepia, grass, cherry, sky, solarized, gruvbox, nord)
- Light/dark mode
- Current page context (library vs reader)

```typescript
// Update theme color meta tag
useEffect(() => {
  const bg = palette['base-100'];
  if (isWebAppPlatform()) {
    document.querySelector('meta[name="theme-color"]')?.setAttribute('content', bg);
  }
}, [themeMode, themeColor]);

// Context-specific colors
updateAppTheme('base-200');  // Library page (subtle background)
updateAppTheme('base-100');  // Reader page (bright background)
```

### Navigation Optimization

**Page Reload Prevention** (`src/utils/nav.ts`):

```typescript
export const navigateToReader = (router, bookIds, queryParams, navOptions) => {
  const ids = bookIds.join(BOOK_IDS_SEPARATOR);
  
  if (isWebAppPlatform() && !isPWA()) {
    // Standard web: URL path navigation
    router.push(`/reader/${ids}${queryParams ? `?${queryParams}` : ''}`, navOptions);
  } else {
    // PWA: Query parameter navigation (avoids page reload)
    const params = new URLSearchParams(queryParams || '');
    params.set('ids', ids);
    router.push(`/reader?${params.toString()}`, navOptions);
  }
};
```

**Benefits**:
- Preserves service worker state
- Faster navigation between library and reader
- Maintains scroll position
- No flash during page transitions

### Platform Detection

**Utility Functions** (`src/services/environment.ts`):

```typescript
export const isPWA = () => 
  window.matchMedia('(display-mode: standalone)').matches;

export const isWebAppPlatform = () =>
  process.env['NEXT_PUBLIC_APP_PLATFORM'] === 'web';
```

**Usage**:
```typescript
// Conditional safe area padding
{isPWA() && 'pb-[env(safe-area-inset-bottom)]'}

// Different navigation strategies
if (isWebAppPlatform() && !isPWA()) {
  // Browser behavior
} else {
  // PWA behavior
}
```

### PWA vs Native Comparison

| Feature | PWA | Native (Tauri) |
|---------|-----|----------------|
| **Installation** | Via browser | OS installer |
| **Updates** | Automatic (service worker) | Manual/auto-updater |
| **Offline** | Service worker cache | Full filesystem |
| **File Access** | IndexedDB only | Native filesystem |
| **Permissions** | Limited (web APIs) | Full (OS APIs) |
| **Performance** | Good (JIT) | Excellent (native) |
| **Distribution** | Web URL | App stores/direct download |
| **Size** | ~5 MB cached | ~50 MB installed |
